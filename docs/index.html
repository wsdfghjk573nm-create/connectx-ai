What the full app does

Features

Everything below is implemented in the full server app in this repository — described plainly, including what is not there yet.

💬

Real-Time Messaging

1:1 and group messages delivered instantly over a live connection, with delivery and read receipts, typing indicators, replies, edits, reactions, pins, search, scheduled messages and disappearing messages.

👥

Groups & Communities

Groups with admin controls and invite links, temporary groups that archive themselves, and communities with multiple channels — including broadcast channels where only admins can post — plus built-in polls.

📞

Voice & Video Calls (1:1 WebRTC)

One-to-one voice and video calls in the browser, with mute controls, screen sharing where the browser supports it, and a call history. Group calls are not available in this version — the app says so instead of showing a fake button.

✨

AI Assistant

An optional helper for writing — leave applications, meeting requests, introductions — plus common Hindi⇄English phrases and a “Summarize this chat” button that runs only when you press it in that chat. Private chats are never sent anywhere automatically.

🔒

Privacy & Security

Hashed passwords, revocable device sessions, login rate limiting, blocking and reporting, and controls for who sees your photo and last-seen status. Honestly: E2E encryption is NOT implemented in this version — messages are protected in transit over HTTPS and stored on the server for multi-device sync.

📎

Files & Media

Share images, videos, documents and voice notes up to 25 MB, with type checks on the server. Downloads are restricted to people in that conversation, and a low-data mode stops images loading automatically.

About

One app you can actually run yourself

ConnectX AI was built as a complete, working messaging platform — not a mock-up. It has a real backend, a real database, real sign-in with hashed passwords, and real-time delivery between separate accounts, all verified by an automated test suite that starts the actual server.

It was built in stages on purpose: first secure accounts and real-time one-to-one chat, then groups, media and communities, then one-to-one calls and the optional assistant. The design stays deliberately honest — a feature that is not finished is labelled as not available, never faked.

The core is free. The intended future revenue in the original plan is premium themes, business tools, advanced community management, extra storage and premium assistant features. Private message content is never sold, and chats are never used for advertising.

Run the real thing

How the full version works

This page cannot run accounts or a database — GitHub Pages only serves static files. The full app is a small Node.js server in this same repository. Running it takes two commands:

1

Get the code

Open the GitHub repository and download or clone it to your computer. You need Node.js 22.5 or newer.

git clone https://github.com/wsdfghjk573nm-create/connectx-ai
2

Install

Install the small set of server dependencies. The database is created automatically on first run — there is no database server to set up.

npm install
3

Start

Start the server, then open it in your browser. Create an account, and open a second browser or device to chat between two real accounts.

npm start # then open http://localhost:3000

Honest limits of the full version

  • No E2E encryption in this version — protected in transit over HTTPS, stored server-side for sync. The app itself says this in its Privacy pages.
  • Calls are 1:1 only — group calls are not available.
  • No SMS / OTP and no push service — a phone number is a sign-in identifier with a password; notifications are in-app.
  • Local database by default — a zero-setup embedded database for local and small use; a move to a larger database for production is documented in the README. No scale claims are made.
  • The assistant is local by default — an optional external AI route exists behind a server key, is off by default, and is untested with a live key.
